# ラッシュアワーパズル

6×6の駐車場から赤い車Aを右の出口へ逃がす、日本語の数学教材です。外部ライブラリ・サーバー・外部音声ファイルを使わず、GitHub Pagesで公開できます。

## 遊び方

- 初級・中級・上級から問題1〜10を選択します。固定配置なので同じ問題を何度でも遊べます。
- マウスでドラッグ、スマートフォン・iPadでは指でスワイプします。車は向いている方向にだけ動き、離すと最も近い合法位置に止まります。
- 赤い車を出口の先までドラッグするとクリアです。出口を通る操作も1手。右端まで移動した後で脱出させる場合は別々の2手になります。
- 何マス動かしても1手。元へ戻す通常操作も1手。動かない操作は0手です。
- 「戻す」は直前の操作と手数を取り消します。「最初から」で初期配置に戻ります。
- ヒントは現在の配置からBFSで最短解を探索し、車・方向・移動先を示します。自動で車は動きません。
- 音は初期OFF。音ONを押すとWeb Audio APIによる効果音を有効にします。
- キーボードではTabで車を選び、矢印キーで1マス移動できます。赤い車が右端に達したら、さらに右矢印で脱出します。
- 最短手数はクリア後だけ表示します。ESCまたは「盤面を見る」で結果画面を閉じられます。

## 公開・起動

GitHub PagesのSettings → Pagesで、このブランチのルートを公開してください。ローカルでは `python3 -m http.server 8000` を実行し、`http://localhost:8000` を開きます。ES ModulesとWorkerを使うので、HTMLファイルを直接開かずHTTPで配信してください。

## ファイル構成

- `engine.js`：合法移動・衝突・履歴・BFS。1回の任意距離の移動を1辺として探索。
- `puzzles.js`：固定30問と検証済み最短手数。
- `app.js` / `style.css` / `index.html`：操作・表示・音・クリア演出。
- `solver-worker.js`：現在盤面の探索を別スレッドで実行。問題変更時はキャンセル。
- `access-counter.js`：ページ読込時の1回だけ共通GASにGET、no-cors送信。失敗は無視。
- `scripts/generate.mjs`：固定シード78291で候補を生成してBFSで選別。通常プレイには不要。
- `tests/game.test.js`：別実装BFSとの照合・途中盤面・ルール・記録通信テスト。

## 問題と探索

初級は4〜8手、中級は10〜16手、上級は19手以上を採用範囲としました。実際の各問題の値は [TEST-RESULTS.md](TEST-RESULTS.md) に記載しています。車の台数では選別しません。上級では同じ車を繰り返し動かす長い依存関係が必要になります。難易度は探索上の基準であり、生徒による実測評価は未実施です。

赤い車の座標6を脱出済み状態とします。出口まで障害物がない場合に、その位置へ直接移動する辺を生成します。右端の盤内位置から脱出する場合も1辺です。ゲームと探索が同じ合法移動関数を使い、さらにテストの別実装BFSで最短手数を照合します。

アクセス設定は隣接の既存教材 `hit-and-blow/access-counter.js` および他教材で確認した共通URLとオプションを使用。識別子は `app=rush-hour-puzzle`。no-corsのためサーバー側での記録成功はブラウザから確認できません。

## 検証

Node.js（外部パッケージ不要）で `npm test`。全30問の検証、途中の到達可能盤面の最短ヒント、長距離1手・戻す・衝突・境界・脱出・ログ通信失敗の33テストを実行します。結果一覧を `TEST-RESULTS.md` に出力します。

ブラウザ検証はPlaywrightとインストール済みChromeがある環境で `node scripts/browser.mjs`。必要なら `PLAYWRIGHT_MODULE` にPlaywrightのパスを指定します。モバイル幅でのタッチ用PointerEvent、マウスドラッグ、クリア、Undo、リセット、Workerヒント、問題選択、通信失敗時の継続、横スクロールがないことを検証しました。タッチは合成イベントによる検証です。iPad Safari・スマートフォン実機での指操作や音声再生は未確認です。
